# FlyAI 命令参考（精简版）

完整文档见 [flyai-skill](https://github.com/alibaba-flyai/flyai-skill/tree/main/skills/flyai/references)。

## ai-search

自然语言语义搜索，适合行程规划、混合意图。

```bash
flyai ai-search --query "五一去杭州玩三天，预算人均2000"
```

## keyword-search

关键词综合搜索：酒店套餐、门票、签证、邮轮等。

```bash
flyai keyword-search --query "杭州三日游"
```

## search-hotel

| 参数 | 说明 |
|------|------|
| `--dest-name` | 目的地（必填） |
| `--poi-name` | 附近景点 |
| `--check-in-date` / `--check-out-date` | 入住离店 |
| `--max-price` | 每晚最高价 |
| `--sort` | `rate_desc` 评分优先 / `price_asc` 低价优先 |

## search-flight / search-train

| 参数 | 说明 |
|------|------|
| `--origin` | 出发地（必填） |
| `--destination` | 目的地 |
| `--dep-date` | 出发日期 |
| `--sort-type` | 3=低价优先，8=直飞优先 |

## search-poi

| 参数 | 说明 |
|------|------|
| `--city-name` | 城市（必填） |
| `--keyword` | 景点名 |
| `--category` | 自然风光、历史古迹、博物馆等 |

## 输出格式

所有命令输出**单行 JSON** 到 stdout；本项目 Python 封装会自动解析。

成功时通常包含：

- `status`: 0
- `message`: "success"
- `data`: 结果数据
- `systemMessage`: 平台提示（展示在攻略末尾）

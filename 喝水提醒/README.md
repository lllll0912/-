# 喝水提醒

定点提醒喝水、记录饮水量的小工具。

## 日常使用

双击 **`run.bat`** 启动即可。

## 可选设置（在 `scripts` 文件夹里）

| 文件 | 作用 |
|------|------|
| `设置每天9点30自启.bat` | 开机后每天 9:30 自动打开本程序 |
| `取消每天自启.bat` | 取消上面的自动启动 |
| `后台启动.bat` | 无黑窗口启动（一般不用手动点） |

## 说明

- 提醒按固定时间点（默认 9:30 起每 1.5 小时），点「喝了一杯」不会重置计时
- 饮水记录保存在 `data/`（不会上传到 GitHub）
- 点 **📊** 展开按日统计图表；点 **⚙** 查看今日记录与设置

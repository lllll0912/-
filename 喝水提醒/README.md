# 喝水提醒小工具

定时提醒喝水、记录饮水量，并查看每日/每周/每月统计图表的 Windows 桌面小工具。

## 功能

- **定点提醒**：从每日指定时间（默认 9:30）起，每隔固定小时提醒（默认 1.5 小时），不受点击喝水影响
- **一键喝水**：点击「喝了一杯」仅记录，不重置提醒计时
- **悬浮小窗**：可拖动、可自由调节大小，显示倒计时与下次定点时间
- **到点放大**：到达提醒时刻窗口自动放大，引导记录饮水
- **任务栏图标**：蓝色水滴主题图标

## 环境要求

- Python 3.10+
- Windows（也可在其他支持 Tkinter 的系统运行）

## 每日自动启动（推荐）

双击 `install_autostart.bat`，可注册 Windows 计划任务：**每天 9:30 自动启动**（静默、无黑窗口）。

- 若程序已在运行，不会重复打开
- 取消自动启动：运行 `uninstall_autostart.bat`
- 要求：9:30 时电脑已开机并已登录

## 快速启动

双击 `run.bat`，或在项目目录执行：

```bash
pip install -r requirements.txt
python main.py
```

## 使用说明

**常态：右下角悬浮小窗**
- 显示倒计时和今日饮水量
- 点击 **「喝了一杯」** → 自动记录 1 杯并重置计时
- 点击 **⚙** 打开设置、记录管理、统计图表
- 拖动顶部标题栏可移动位置

**到点提醒：窗口自动放大**
- 计时结束后窗口居中放大，提示喝水并展示输入界面
- 提交记录或点「稍后」→ 窗口缩回小窗，重新开始计时

1. 首次使用在设置中配置提醒频率和每杯水量
2. 平时只需关注小窗倒计时，喝完点一下即可
3. 误录记录可在设置窗口中编辑或删除

## 数据存储

饮水记录和设置保存在 `data/water_data.json`，无需数据库。

## 注意

程序需要保持运行（可最小化）才能持续定时提醒。关闭窗口后提醒会停止。

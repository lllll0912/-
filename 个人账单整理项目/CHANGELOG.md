# Changelog

所有重要变更会记录在这里。

## [2026-03-20-r10] - 2026-03-20

### Added
- 旅游管理页新增“同行人”字段（文本输入），支持在按日期打标时同步写入数据库。
- 旅游专题统计与已打标日期列表新增“同行人”展示列，便于识别同趟出行人员。
- 备份增强：除原有 `types.json`、`travel.json` 外，新增 `types.csv`、`travel.csv` 两份可查阅表格文件。

### Changed
- `records` 表新增 `travel_companions` 字段，并自动迁移历史库结构。
- 导入确认覆盖时，旅游快照回填从仅回填 `travel_tag` 扩展为同时回填 `travel_tag + travel_companions`。
- 清除旅游打标时同步清空同行人字段，保证语义一致。

## [2026-03-20-r9] - 2026-03-20

### Fixed
- 修复记录页日期级联：点击“清空”后再“应用”可正确把日期筛选置空，恢复无日期筛选状态。
- 修复日期级联交互：点击年/月/日条目本体不再误关闭列表，改为直接勾选/取消对应层级值，支持连续多选。

### Changed
- 全站表格新增通用列头点击排序（升序/降序切换）：
  - 支持文本、数字、日期值排序。
  - 输入框/下拉框所在单元格按当前值参与排序。
  - 点击列头空白区域触发排序，避免干扰列头内原有按钮/链接操作。

## [2026-03-20-r8] - 2026-03-20

### Fixed
- 修复“使用2025样例”在导入页偶发失效：样例加载后跳过本页草稿回填，避免 `localStorage` 旧草稿覆盖服务端样例内容。
- 修复记录页日期三级选择器交互：年份/月份行从 `mouseenter` 改为点击切换，避免 hover 重绘导致一级/二级勾选框操作不生效。

### Changed

  - 覆盖模式（按导入日期先删后插，默认）
  - 仅插入模式（不删除旧记录）
- 入库确认逻辑支持按模式执行，成功提示文案同步区分覆盖/仅插入。

### Tests
- 单元测试通过：`tests/test_importers.py`、`tests/test_parser.py`。
- 语法检查通过：`app.py`、`db/repository.py`、`importers.py`、`parser.py`。

# 个人账单整理（数据库版）

## 一键启动（推荐）

在项目根目录打开终端，**只需一条命令**：

```bash
./run.sh
```

首次运行会自动：创建 `.venv`、安装 `requirements.txt`、启动服务。浏览器打开 **http://127.0.0.1:8501**。

- **Windows**：双击或在 CMD 里执行 `run.bat`
- 自定义虚拟环境目录：`BILL_VENV=.myvenv ./run.sh`
- 手动步骤：`python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && python app.py`

## 二级类型体系

本系统采用 **一级类型（大类）→ 二级类型（细分）** 的两层分类结构：

| 一级类型 | 二级类型示例 |
|---------|------------|
| 生活支出 | 医药、宠物、购物、个人护理、日用家居、其他生活 |
| 虚拟充值/通讯 | VPN、会员、水电燃费、通信费 |
| 食品饮料 | 食品饮料 |
| 交通 | 交通 |
| 娱乐/运动 | 娱乐/运动（可继续拆分） |
| ... | ... |

- 规则配置存储在 `category_rules.json`，格式为 `{ L1: { L2: "正则", ... } }`
- 自动推断时返回 `(一级类型, 二级类型)` 对
- 数据库 `records` 和 `staging_records` 表均包含 `category_l1`（一级）和 `category`（二级）字段
- 兼容旧版扁平结构，启动时自动迁移

## 页面与功能

### 1. 导入清洗页 `/`

| 功能 | 说明 |
|------|------|
| 多格式导入 | 支持 `txt / csv / xlsx`，粘贴文本或上传文件 |
| 账单年份补全 | TXT 中 `MM-DD` 格式自动补全指定年份 |
| 解析预览 | 自动分类（含一级+二级），高亮待分类行（红色）和待映射类型行（橙色） |
| 分组下拉 | 二级类型下拉按一级类型 `<optgroup>` 分组，选择后自动推导一级类型 |
| 类型标准化映射 | 导入数据中包含当前字典不存在的类型时，提示映射到标准二级类型 |
| 自动分类 + 学习 | 基于 `category_rules.json` 正则匹配；手动归类后自动学习 |
| 行内编辑/删除 | 预览表支持逐行修改、删除、按日期批量删除 |
| 入库覆盖 | 确认入库时，自动删除目标日期范围内旧记录再写入 |

### 2. 数据库记录页 `/records`

| 功能 | 说明 |
|------|------|
| 默认展示 | 最近 20 条；有筛选条件时展示全部 |
| 关键词搜索 | 模糊匹配明细字段 |
| 表头点击筛选 | 日期、方向、一级类型、二级类型、旅游标识均可通过表头点击筛选 |
| 日期树选择器 | 年-月-日三级多选弹窗（`DateTreePicker`） |
| 行内编辑 | 直接修改字段值并保存（修改二级类型后一级类型自动推导） |
| 批量删除 | 通过日期树选择器选择日期后批量删除 |

### 3. 分析看板 `/analysis`

| 功能 | 说明 |
|------|------|
| 年度日历热力图 | 支持切换支出/收入视图 |
| 年度总额 + 每月汇总 | 热力图旁显示年度和月度金额 |
| 热力图点击跳转 | 点击日期格子自动跳转记录页并筛选该日 |
| 类型-方向-月汇总表 | 显示一级类型+二级类型列，筛选交易方向和多个类型，按月聚合统计 |

### 4. 旅游管理 `/travel`

| 功能 | 说明 |
|------|------|
| 旅游打标 | 通过日期树选择器选择日期，输入目的地标签，直接同步数据库 |
| 清除标签 | 选择日期清除对应旅游标识 |
| 已打标日期 | 展示当前已标记的旅游日期 |
| 行程标签统计 | 显示开始日期、结束日期、持续天数、总金额 |
| 月度旅游/非旅游对比 | 按月对比旅游与非旅游支出 |
| 旅游支出类型 Top12 | 旅游消费二级类型排行 |

### 5. 类型字典管理 `/types`

| 功能 | 说明 |
|------|------|
| 二级结构管理 | 每条规则显示：一级类型、二级类型、匹配正则 |
| 可交互增删改 | 每行可编辑并保存，支持删除；底部表单新增 |
| 同组视觉分隔 | 不同一级类型组之间有分隔线 |

### 6. 离线报告包

| 功能 | 说明 |
|------|------|
| 一键下载 | 导航栏"离线报告包"按钮，下载 `offline_report.zip` |
| 内容 | 自包含 `report.html` + `data.json`，含一级/二级类型字段 |
| 跨平台 | 任意系统浏览器直接打开查看 |

## TXT 清洗逻辑

### 输入约定

- 日期头：`MM-DD；当天备注`（年份通过页面"账单年份"字段补全）
- 明细行：`类型明细；金额；交易方向/类型...`
- 空行分隔不同日期块

### 类型自动匹配

- 使用 `category_rules.json` 的二级嵌套结构进行正则匹配
- 匹配返回 `(一级类型, 二级类型)` 对
- 未命中标记为 `("待分类", "待分类")`
- 手动指定后自动学习该明细到对应的二级类型规则中

## CSV / XLSX 导入

### 必填字段

`日期` / `金额` / `类型明细` / `交易方向`（收入 或 支出）

### 可选字段

`日记` / `类型`（二级类型名） / `一级类型` / `旅游标识`（1/0 或 是/否） / `旅游标签`

模板下载：`/download/template.csv` 、 `/download/template.xlsx`

## 本地备份机制

每次成功入库后自动生成（覆盖旧备份）：

| 文件 | 说明 |
|------|------|
| `backup/<时间戳>_records.csv` | 全量记录 CSV（含 category_l1） |
| `backup/<时间戳>_records.txt` | 全量记录 TXT |
| `backup/<时间戳>_types.json` | 类型字典配置（二级结构） |
| `backup/<时间戳>_travel.json` | 旅游配置 |

## 项目结构

```
├── preview_store.py        # 预览数据内存存储
├── offline_report.py       # 离线报告生成（含 L1 字段）
├── category_rules.json     # 类型匹配规则（二级嵌套结构）
├── run.sh / run.bat        # 一键启动脚本
├── requirements.txt        # Python 依赖
├── db/
│   ├── connector.py        # 数据库连接
│   ├── schema.py           # 建表 DDL + 迁移（含 category_l1）
│   ├── repository.py       # 数据访问层（含 L1 字段）
│   └── backup.py           # 备份逻辑（含 L1 字段）
├── templates/
│   ├── layout.html         # 基础布局（导航 + 公共组件 + DateTreePicker）
│   ├── import.html         # 导入清洗页（optgroup 分组下拉）
│   ├── staging.html        # 临时表页
│   ├── records.html        # 数据库记录页（含一级类型筛选列）
│   ├── analysis.html       # 分析看板（汇总含 L1+L2）
│   ├── travel.html         # 旅游管理页
│   └── types.html          # 类型字典管理页（二级结构交互）
├── tests/
│   ├── test_parser.py      # 解析器测试（含 L1/L2 验证）
│   ├── test_importers.py   # 导入器测试
│   └── test_rule_manager.py # 规则管理测试（含二级结构）
└── backup/                 # 自动生成的备份目录
```

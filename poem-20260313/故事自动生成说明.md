# 诗境故事 · 自动生成说明

## 方案（推荐：API + 大模型）

| 步骤 | 做什么 | 工具 |
|------|--------|------|
| 1 | 按名句查出处、全诗、作者生平 | 古诗文检索 API（免费） |
| 2 | 写背景、解读、主旨 | 大模型（可选，质量更好） |

**不建议**完全手填 237 条，也**不必**绑死某一个诗词网站会员——我们用公开检索接口 + 你自己的大模型 Key（一次配置，长期自动）。

## 一次配置大模型（推荐 DeepSeek，很便宜）

1. 复制 `.env.example` 为 `.env`
2. 填入 `POEM_LLM_API_KEY`（DeepSeek / OpenAI 兼容均可）
3. 之后生成会自动用大模型润色解读

不配 Key 也能跑：只用诗词 API 生成基础版故事（出处+全诗+模板解读）。

## 命令

```bash
cd poem-20260313

# 补全所有缺失故事（首次跑全库约 2-5 分钟）
python scripts/generate_stories.py --all --no-llm

# 有大模型 Key 时（去掉 --no-llm）
python scripts/generate_stories.py --all

# 只补新增诗句（日常用这个）
python scripts/generate_stories.py --only-missing
```

## 你以后只要加诗句

1. 在 `poem.txt` 里按日期加新句  
2. 告诉我「加了新诗」或自己跑发布脚本  
3. 我会执行 `publish_to_github.ps1`：自动 `--only-missing` → 构建 → 推送 GitHub → Netlify 自动更新

## 数据文件

- `stories.json`：每条 id 对应结构化故事（可人工微调）
- 构建后写入 `site/poems.json` 供网页读取

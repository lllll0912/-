# 选不到 Render 仓库时怎么办

仓库名 `-` 在 Render 里经常搜不到 / 选不了。换下面任一方式即可。

---

## 方式 A（推荐，最快）：Netlify 拖拽

已为你准备好文件夹：`poem-20260313\deploy-repo`

1. 打开 https://app.netlify.com/drop （可用邮箱或 GitHub 登录）
2. 把 **`deploy-repo` 整个文件夹**拖进网页
3. 立刻得到 `https://随机名.netlify.app` —— 把链接发给别人即可  
   （国内多数情况不用 VPN）

想改成固定名字：站点设置里改 Site name。

---

## 方式 B：新建干净仓库 `daily-poem` 再连 Render

1. 打开 https://github.com/new ，仓库名填 **`daily-poem`**，选 **Public**，不要勾选 README，创建  
2. 告诉我「仓库建好了」，我帮你把站点推进去  
3. 再到 Render → **New → Static Site**（不要用 Blueprint）→ 选 **`daily-poem`**  
   - Build Command：`true`  
   - Publish Directory：`.`  
4. 若仍看不到：打开 https://github.com/settings/installations → Render → Configure → 勾选 `daily-poem` → Save

---

## 方式 C：修好对旧仓库 `-` 的授权

1. https://github.com/settings/installations  
2. 找到 **Render** → Configure  
3. Repository access 选 **All repositories**，或只勾选 `-`  
4. Save 后回 Render 刷新再选仓库

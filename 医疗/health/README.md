# 健康档案

## 功能

| 页面 | 说明 |
|------|------|
| `/health/calendar` | 医疗日历 + 类别/说明筛选 |
| `/health/calendar` | 医疗日历（含页内上传 / 搜索） |
| `/health/records` | 按类别 / 关键词搜索 |

类别：检验单、门诊单、用药（另保留中药方/体检/病史）。

## 数据与 GitHub

- 本机上传写入 `医疗/数据/{类别目录}/`，并更新 `_meta/catalog.json`
- 记录里有 `github_path`（如 `医疗/数据/05_本人_门诊单/...`）
- **本机上传后 `git push`，私密仓即与本地一致**
- 正式站读镜像内旧图 + Volume 新上传；重要材料建议本机上传再推送

# backup（隐私 · 不进 Git）

| 场景 | 落点 |
|------|------|
| 本机 `run.bat` | **直接**写到项目根 `backup/`，不用再整理下载 |
| 正式站（Fly） | 服务器 `/data/backup/`；浏览器侧栏 **绑定本机 backup** 后，入库/改类型/旅游会**自动写入你选的文件夹** |
| 未绑定 / 不支持的浏览器 | 侧栏「导出备份」或提示里的「仍下载 zip」，再解压到 `backup/` |

| 内容 | 说明 |
|------|------|
| `records_backup_*` | 账单 + 类型字典 + 旅游打标的一套导出 |
| `原始账单/` | 历年 xlsx/docx 等原始归档 |

**第一次用正式站**：侧栏点「绑定本机 backup」→ 选中本项目里的 `backup` 文件夹 → 以后自动写入，无需改浏览器下载路径。

# 个人网站

私人综合站：账单、生活日志、喝水、诗词、笔记专栏。

## 访问

| | |
|--|--|
| **正式站** | https://bill-private-lllll0912.fly.dev |
| **本机** | `run.bat` → http://127.0.0.1:8501 |
| **上线方式** | `git push origin main` → GitHub Actions 自动部署到 Fly（不要本地直接 `fly deploy`，除非应急） |

打开网站先选模式：

- **所有者模式**：输入访问密码，可用全部功能（含编辑）
- **游客模式**：无需密码，仅可**查看**诗词与笔记专栏

## 大致介绍

- **账单财务**：导入清洗、记录、分析、类型、旅游标签  
- **生活日常**：生活日志、喝水提醒（含网页小窗）  
- **诗意**：每日诗词（游客只读；维护需所有者）  
- **笔记专栏**：Markdown 图文笔记（游客只读；所有者增删改）  

数据分三块：账单库、诗词库、笔记库（图片随笔记资源目录）。私密仓库下由 Actions 定期把云端数据打包备份到 GitHub。

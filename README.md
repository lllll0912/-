# 本地项目合集

本仓库包含多个个人项目，通过 Git 同步到 **你自己的 GitHub 账号** 进行备份。

| 目录 | 说明 |
|------|------|
| `喝水提醒/` | 定点喝水提醒桌面小工具 |
| `个人账单整理项目/` | 个人账单导入、分类与统计 |
| `poem-20260313/` | 诗词相关 Web 项目 |

---

## 连接 GitHub（必读）

**三件事是分开的：**

| | 可以用谁的 |
|--|-----------|
| Cursor 账号（AI） | 可以是别人的 ✓ |
| **GitHub 账号（存代码）** | **必须是你自己的** |
| Windows 用户名 | 和 GitHub 无关 |

详细步骤见 → **[GitHub连接教程.md](./GitHub连接教程.md)**（含「别人的 Cursor + 自己的 GitHub」专节）

---

## 日常备份

改完代码后，在 Cursor 源代码管理里 **提交 + 同步**，或双击 `sync_github.bat`。

---

## 注意事项

- 账单备份、饮水记录等个人数据已在 `.gitignore` 中排除，不会上传
- 建议使用 **Private 私有仓库**
- 喝水提醒每天 9:30 自启：`喝水提醒/install_autostart.bat`

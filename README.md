# 我的项目

四个小项目，代码已备份到 GitHub：`https://github.com/lllll0912/-`

## 项目（点开文件夹即可）

| 文件夹 | 干什么 | 怎么启动 |
|--------|--------|----------|
| **喝水提醒** | 定时提醒你喝水 | 双击 `喝水提醒\run.bat` |
| **飞猪MCP** | 飞猪旅行查询、生成攻略 | 先装 Node.js，再双击 `飞猪MCP\scripts\安装依赖.bat`，然后 `飞猪MCP\run.bat` |
| **个人账单整理项目** | 账单导入分析（本机）+ 公网演示 | 双击 `run.bat`；演示见 `site/`；说明 `README.md` |
| **poem-20260313** | 每日一诗（公开网页） | 双击 `预览本地.bat`；说明见 `poem-20260313\README.md` |

## 其他文件夹

| 文件夹 | 干什么 |
|--------|--------|
| **文档与工具** | GitHub 备份（每天 12:00、21:00 自动推送） |
| **喝水提醒\scripts** | 喝水提醒的高级设置（开机自启等，按需使用） |

## 改完代码想备份到 GitHub

- **已开启定时自动备份**：每天 **12:00** 和 **21:00** 自动推送（有改动才提交）
- 手动备份：双击 **`文档与工具\备份到GitHub.bat`**
- 取消定时：双击 **`文档与工具\取消定时自动备份.bat`**

或在 Cursor 里：源代码管理 → 提交 → 同步。
